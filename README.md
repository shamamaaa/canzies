# Canzies

Can'a adanmış resmi olmayan bir hayran topluluğu sayfası. Müzik, videolar ve sevgi dolu hayran mektupları içeren tek sayfalık bir site.

## İçerik

- `index.html` — tek dosyalık site (HTML/CSS/JS bir arada)
- `can.png` — site görseli

## Kullanım

Depoyu klonlayıp `index.html` dosyasını bir tarayıcıda açman yeterli:

```bash
open index.html
```
